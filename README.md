## 💡 The Manifesto: Why Lists Fail

Traditional to-do apps are **bottomless digital graveyards**. You write down 40 tasks, scroll past items you entered six months ago, feel a creeping sense of burnout, and close the tab.

> **Infinite scroll hides cognitive overload.**
> When your physical desk is overflowing with papers, you *see* the boundary immediately. But when a software list overflows, it just quietly adds another scroll pixel.

**WorkStash treats tasks as physical blocks on a bounded 2D canvas.** 
- Every task occupies real cognitive real-estate.
- Size equals mental friction.
- Capacity is strictly limited by design.
- If it doesn't fit on your board, **it doesn't fit in your day.**

### 🍱 1. The Shape-Shifting Bento Canvas
Tasks are not uniform checklist lines. They adapt to the true cognitive weight of the work:
- **`1×1 Micro Admin`** — Instant tap-to-complete button for quick admin wins.
- **`2×1 Checklist Strip`** — Horizontal subtask card with real-time done/total progress counters.
- **`2×2 Focus Hub`** — Tabbed powerhouse combining Markdown notes, subtasks, and countdown timers.
- **`3×2 Deep Matrix`** — Full split-pane command center for master architectural tasks.
- **Live Corner Drag-Resize** — Grab the bottom-right handle of any block to dynamically resize its footprint on the fly.

### 📐 2. The Capacity Ceiling
The header features an interactive **Capacity Gauge** (`6×4`, `8×4`, or `6×5` grids). When your board hits 100%, you are strictly prevented from hoarding more tasks until you finish, downsize, or defrag. **Honesty built into the physics of the UI.**

### ⚡ 3. Four Dynamic Board Topologies
Reshape the board to match your current mental energy in one click:
- 🌐 **All Blocks** — Full 2D spatial eagle-eye view of your workspace.
- 🎯 **Solo Focus** — One chosen task commands center stage; all other blocks quietly park.
- 🔥 **Urgent First** — High-priority fire tasks stack up front while calm blocks compress.
- 🧹 **Admin Sweep** — Isolates micro administrative chores for rapid batch clearing.

### 🔥 4. The Ember Pomodoro Engine
Anchored at the bottom-left is **The Ember** — an animated floating focus coal:
- Cycles through **25m Deep Focus**, **5m Breath**, and **15m Long Tide** intervals.
- Automatically attaches to whichever task block timer you trigger.
- Color shifts from violet to glowing amber as time runs low.

### 📥 5. The Off-Grid Inbox (Holding Pen)
Distractions happen mid-flow. The floating bottom-right **Inbox Dock** gives you a rapid-capture buffer that **never consumes grid capacity**. Stash ideas instantly, and drag them straight onto the board whenever you're ready to commit.

### 🪄 6. Spatial Bloom Workspace Menu
A morphing, glassmorphic dropdown trigger in the header that blooms outward into:
- 🔄 **End-of-Day Defrag** — An animated consolidation ritual that sweeps finished work off the board with an ascending chord fanfare.
- 📦 **Archive Vault** — Search, inspect, and restore previous tasks.
- ⏰ **Rhythm Engine** — Manage daily, weekly, and monthly recurring routines off-grid.

### 🎵 7. Synthesized Zero-Asset Audio Pack
Experience pure tactile delight with a custom Web Audio synthesizer library. Zero audio files, zero network bandwidth, zero latency:
- High-satisfaction tactile clicks, energetic complete chimes, defrag chord sweeps, and subtle DND drop thuds.
- Audition any tone live in the **Soundboard Settings**.

### 🌗 8. Obsidian Glow & Porcelain Light Modes
- **Obsidian Dark**: Midnight slate with ambient chromatic mouse spotlights, neon laser borders, and soft glass glow.
- **Porcelain Light**: Inspired by Linear and Apple interfaces — crisp white cards, rich `#0D0F1A` high-contrast typography, and deep indigo accents.

### 📝 9. Live Markdown Scratchpads
Every block includes a rich notes scratchpad with real-time rendering for **bold**, *italics*, `inline code pills`, blockquotes, and bullet lists.

### 🧭 10. Interactive Spotlight Onboarding
First time opening the app? A guided spotlight tour with an SVG cutout window highlights real UI elements while explaining the spatial productivity paradigm with witty, memorable copy.

## ⌨️ Keyboard Shortcuts

WorkStash is engineered for keyboard-first flow:

| Shortcut | Action | Description |
|:---|:---|:---|
| <kbd>F</kbd> | **Focus Shutter** | Hover any task tile to expand it fullscreen |
| <kbd>Esc</kbd> | **Exit / Dismiss** | Closes Shutter, Modals, Tour, and Drawers |
| <kbd>⌘</kbd> + <kbd>Z</kbd> | **Undo** | Reverts tile edits, moves, and deletions |
| <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>Z</kbd> | **Redo** | Steps forward in history state stack |
| <kbd>⌘</kbd> + <kbd>Enter</kbd> | **Quick Submit** | Saves edits or creates tasks instantly |
| <kbd>Double Click</kbd> | **Solo Spotlight** | In Solo Focus mode, sets active single task |
| <kbd>Click #Tag</kbd> | **Tag Spotlight** | Filters and highlights all blocks sharing the tag |

## 🔒 Privacy, Security & Data Sovereignty

- **100% Local-First**: WorkStash runs entirely in your browser. All data resides safely in offline storage.
- **Zero Third-Party Trackers**: No Google Analytics pixels, no advertising SDKs, no behavioral tracking cookies.
- **Auditable Open Source**: Every line of code is open source under the **MIT License**.
- **Encrypted Cloud Sync**: When authenticated, data syncs over SSL directly to your private Firebase Cloud Firestore partition.
- **Full Data Sovereignty**: Export your entire workspace as a portable `.json` backup file anytime or permanently erase your account in a 3-step deletion sequence.

## 🚀 Quick Start

Run WorkStash locally in three commands:

```bash
# 1. Clone the repository
git clone https://github.com/hariharen9/workstash.git
cd workstash

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Open **`http://localhost:5173`** in your browser.

### Available Scripts

| Script | Purpose |
|:---|:---|
| `npm run dev` | Starts the Vite development server with Hot Module Replacement (HMR) |
| `npm run build` | Runs TypeScript typechecks and compiles optimized production assets |
| `npm run preview` | Serves the production build locally for verification |
